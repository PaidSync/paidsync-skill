# Launch a campaign

1. Follow the `paidsync-launch-campaign` skill: agree goal, budget, locations, audience or keywords, landing page and bid strategy first.
2. For search campaigns, use `paidsync-keyword-research` for keywords and `paidsync-ad-copy` for the ads.
3. Show the full draft and create it paused unless the user says to start it live.
4. Read the campaign back and confirm every setting landed as drafted.
