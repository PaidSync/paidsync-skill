# Weekly cross-platform report

1. Use the last 7 full days, compared with the 7 days before, unless the user says otherwise.
2. Follow the `paidsync-cross-platform-report` skill: one table with spend, conversions, CPA and ROAS per platform, currencies named, unreadable accounts listed separately.
3. End with the two or three changes that matter most and what likely caused them.
4. Offer to save it as a workflow so it can be rerun every week (`paidsync-workflows`).
